# Design DNA

## Aesthetics
- **Material 3 Foundation**: Use of nested rounded corners, elevated surfaces, and semantic colors.
- **Product-Led Design**: The UI of the marketing site should feel like an extension of the CRM itself.
- **Human-Designed**: High contrast, deliberate white space, breaking out of generic templates.

## Typography
- **Headings (Hero/Display)**: `Plus Jakarta Sans`, heavy weights (extrabold/bold), tight leading.
- **Body / General UI**: `Roboto`, readable, neutral.
- **Data / Code / Metrics**: `JetBrains Mono` or similar monospaced font for data points to convey technical precision.

## Color Strategy
- **Base (60%)**: Slate/White (bg-slate-50, bg-white, text-slate-900).
- **Primary Brand (25%)**: Deep Teal (`#00695C`, `teal-800`, `teal-900`), Cyan/Emerald for positive actions.
- **Secondary Accents (15%)**: Navy Blue (`#0B1E36`), Indigo for workflows, Violet for AI.

## Layout Rules
- **Asymmetry**: Avoid perfectly centered, boring blocks.
- **Padding Math**: Outer padding must exceed inner padding.
- **Contrast**: Clear distinction between light marketing sections and dark "product showcase" sections.
