# Project Context: DialPulse

## Vision
DialPulse is the "Operating Layer for Sales". It is a product-led CRM that brings lead management, outbound calling (softphone), omnichannel messaging (WhatsApp, SMS, Email), and strict compliance checks into a single, high-performance workspace.

## Target Audience
Modern, high-volume communication teams, enterprise sales, call centers, and any organization managing large pipelines that require strict compliance (DNC, timezone rules) before communication.

## Architecture
- **Frontend**: React (Vite), TypeScript, Tailwind CSS.
- **Design System**: Material 3 semantics adapted for a premium SaaS feel (Deep Teal, Emerald, Navy).
- **Structure**: Client-side SPA, highly componentized.
