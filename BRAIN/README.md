# DialPulse Brain

This directory acts as the central source of truth for the DialPulse project.

## Files
- `PROJECT-CONTEXT.md`: The overarching product goals and architecture.
- `MARKETING-CONTEXT.md`: Information architecture, messaging strategy, and conversion goals.
- `DESIGN-DNA.md`: Typography, color strategy, and structural guidelines (Material 3 + CRM).
- `BRAND-RULES.md`: Absolute constraints on what NOT to do (Anti-Slop rules).
